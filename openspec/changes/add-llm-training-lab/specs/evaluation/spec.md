# Spec Delta

## Purpose

提供统一的模型评测与实验追踪能力，使预训练、微调与对齐各阶段的效果可量化、可比较、可追溯，并支持跨实验的消融与对比分析。

## ADDED Requirements

### Requirement: 语言建模指标
系统 SHALL 在指定验证集上计算并记录困惑度等语言建模指标，支持按模型、检查点与数据版本分别记录，并报告参与计算的 token 数与可能的泄漏检查结果。

#### Scenario: 困惑度评测
- **WHEN** 用户对某个检查点运行语言建模评测
- **THEN** 报告包含困惑度、每 token 平均损失、评测 token 数与耗时

#### Scenario: 数据重叠检查
- **WHEN** 评测数据与训练数据存在可疑重叠
- **THEN** 系统报告重叠样本数量与比例，并标记该评测结果的可信度

### Requirement: 任务与生成评测
系统 SHALL 支持在本地任务基准（如指令遵循、选择题或自定义规则任务）上评测模型，并支持固定提示集的批量生成与评分；评分规则 MUST 可配置，评分过程 MUST 记录规则版本以便复现。

#### Scenario: 规则评分
- **WHEN** 用户运行固定提示集生成评测
- **THEN** 报告包含逐条输出、命中规则、得分与汇总统计，并保存评分规则版本

#### Scenario: 模型输出为空
- **WHEN** 模型对某些提示生成空输出或超长输出
- **THEN** 系统按规则计分并单独统计异常输出数量，不影响其余样本的评测

### Requirement: 实验追踪与本地报告
系统 SHALL 记录每次实验的配置、指标、曲线与产物路径，在无网络环境下仍能完整记录并生成本地可浏览的对比报告；当外部追踪服务可用时 SHALL 可选同步。

#### Scenario: 离线记录
- **WHEN** 机器无外网时运行训练或评测
- **THEN** 指标与报告在本地正常生成，manifest 标记离线模式

#### Scenario: 报告生成
- **WHEN** 用户请求生成对比报告
- **THEN** 输出包含指标表与图表的本地报告文件，引用对应实验目录

### Requirement: 跨实验对比与消融
系统 SHALL 支持跨实验对比（任意两个及以上实验的指标表与曲线），并提供预置对比场景：预训练规模对比、指令微调前后对比、对齐前后对比、两种训练后端对比。

#### Scenario: 两实验对比
- **WHEN** 用户选择两个实验目录进行对比
- **THEN** 系统输出指标差异表与曲线叠加图，并标注配置差异

#### Scenario: 预置对比
- **WHEN** 用户运行预置对比场景
- **THEN** 系统自动定位符合条件的实验并生成该场景的标准报告

### Requirement: 评测可复现
评测 SHALL 支持固定随机种子与采样参数，并提供一键复现命令；相同输入与配置下重复评测的指标差异 MUST 在声明容差内，超出容差时报告差异来源。

#### Scenario: 重复评测一致
- **WHEN** 用户对同一检查点重复运行评测
- **THEN** 指标差异在声明容差内，报告标注两次运行的关系

#### Scenario: 结果不一致
- **WHEN** 两次相同配置的评测结果超出容差
- **THEN** 系统报告不一致的指标项、可能原因与环境差异
