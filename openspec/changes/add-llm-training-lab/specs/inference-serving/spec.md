# Spec Delta

## Purpose

提供把训练产物变成可部署推理服务的能力：模型量化与格式转换、推理性能基准、本地生成接口与兼容主流协议的服务端点，并对照生产级推理栈说明迁移路径。

## ADDED Requirements

### Requirement: 量化与格式转换
系统 SHALL 支持将训练产物转换为至少一种低比特量化格式并支持可选的其他格式，转换后 SHALL 报告模型体积变化、量化配置与可加载性；转换失败 MUST 不覆盖原始模型。

#### Scenario: 量化转换成功
- **WHEN** 用户对指定模型执行量化转换
- **THEN** 系统产出量化模型目录、配置说明与体积对比，并成功加载生成一条样例

#### Scenario: 转换失败
- **WHEN** 量化转换过程中出错
- **THEN** 原始模型保持不变，系统报告失败阶段与错误原因

### Requirement: 推理性能基准
系统 SHALL 测量并报告推理吞吐（每秒生成 token 数）、首 token 延迟与内存峰值，支持配置批次大小、上下文长度与生成长度，并支持不同量化配置与后端的对比。

#### Scenario: 基准测试
- **WHEN** 用户运行性能基准
- **THEN** 报告包含指定配置下的吞吐、首 token 延迟、峰值内存与测试参数

#### Scenario: 对比两种配置
- **WHEN** 用户选择两个推理配置进行对比
- **THEN** 报告并排展示吞吐与内存差异，并标注是否可复现

### Requirement: 本地生成接口
系统 SHALL 提供命令行与编程接口两种生成方式，支持温度、top-p、最大生成长度等采样参数、流式输出与多轮对话会话；非法参数 MUST 在生成前被拒绝。

#### Scenario: 命令行生成
- **WHEN** 用户通过命令行提交提示与采样参数
- **THEN** 系统输出生成文本与本次生成的耗时、token 数统计

#### Scenario: 非法采样参数
- **WHEN** 用户提交超出允许范围的温度或 top-p
- **THEN** 系统返回参数错误与允许范围，不执行生成

### Requirement: OpenAI 兼容服务
系统 SHALL 提供本地 HTTP 服务，兼容主流聊天补全接口的请求与响应格式，支持并发请求、流式响应与错误响应；服务 SHALL 在启动时打印可访问地址并提供调用示例。

#### Scenario: 聊天补全请求
- **WHEN** 客户端向本地服务发送符合协议的聊天补全请求
- **THEN** 返回包含生成内容的兼容响应，响应字段与协议一致

#### Scenario: 并发与错误处理
- **WHEN** 多个客户端并发请求且其中一个请求参数非法
- **THEN** 非法请求返回结构化错误，其余请求正常完成，服务不崩溃

### Requirement: 生产推理栈对照
系统 SHALL 输出本地推理方案与生产推理栈（批处理调度、连续批处理、PagedAttention、张量并行、投机解码等）的能力对照文档，说明单机可体验部分、模拟部分与仅文档说明部分及迁移路径。

#### Scenario: 对照文档
- **WHEN** 用户查看推理阶段课程文档
- **THEN** 文档包含本地与生产栈的逐项能力对照表与迁移建议
