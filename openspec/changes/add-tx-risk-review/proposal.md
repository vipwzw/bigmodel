# Proposal

## Why

币安 2026-10-30 热钱包事件（约 63 亿美元、多条链，链上调查未发现私钥泄露）暴露了一个共性缺口：签名基础设施会校验"谁在请求、请求格式是否合法"，却不会审查"这次签名让渡了什么能力、暴露多少资产、是否符合业务意图"。攻击者通过内部服务容器提交 EIP-7702 委托授权，签名系统照常签发，热钱包执行权被交给攻击者合约。行业已有的规则拦截只能覆盖已知模式，面对"合法格式、错误意图"的新攻击仍会失效。

`bigmodel-lab` 已经具备 SFT、DPO、评测与量化服务的完整训练链路，但还缺一个把"大模型能力"落到真实安全场景的应用实验。本变更新增**交易签名风险审查应用实验（capstone）**：在完全离线、可复现的条件下，实现"解码 → 模拟 → 能力/暴露特征 → 规则决策 → 小模型语义审查 → 评测"的完整链路，并用币安式 EIP-7702 事件做回归用例，同时给出可迁移到生产架构的设计说明。

## What Changes

- 新增 `lab risk` 子命令族：`data`（生成/校验审查数据集）、`review`（单笔或批量签名请求审查）、`train`（训练审查模型）、`eval`（评测与消融对比）。
- 新增交易审查数据能力：统一的签名请求 + 上下文 + 模拟结果 + 标签 schema；合成场景生成器覆盖正常运营、普通转账、approve/permit、EIP-7702 委托、权限变更、批量 nonce、跨链组合；内置币安事件结构化回归用例；数据卡与可复现划分。
- 新增离线审查引擎：EVM calldata、EIP-712、EIP-7702 授权解码；确定性状态模拟（余额/授权/权限/代码差分）；能力变化（capability delta）与最坏情况资产暴露计算；规则/不变量引擎；四档决策（ALLOW / STEP_UP / BLOCK / ESCALATE）与 JSON 审查报告。引擎不接触私钥、不广播交易，模拟或解码失败时 fail-closed。
- 新增审查模型训练与集成：把审查样本转换为 SFT（可选 DPO）数据，复用 Qwen3-0.6B LoRA 训练、评测与量化服务链路；模型输出受 JSON schema 约束，必须给出证据字段与不确定度；模型缺失或超时时规则基线仍可用；模型只作为"第二意见"，高风险操作的最终放行仍由确定性策略决定。
- 新增评测能力：按场景族和时间切分的标注集、攻击类型召回、固定 FPR、资产加权召回、决策延迟；规则基线 vs 规则+模型的消融；币安回归用例必须通过；报告可复现。
- 新增应用实验文档与 README/课程导航入口，说明本机教学模拟器与生产级模拟器（fork/RPC）的差异、已知限制与迁移路径。
- **Out of scope**：真实私钥管理与签名、链上交易广播、生产部署与实时监控、全链支持（v1 只覆盖 EVM 语义，BTC/Solana 仅文档对照）、大模型能力提升（仅 0.6B 级别演示）、真实用户数据或真实攻击资金。

## Capabilities

### New Capabilities

- `tx-risk-data`: 交易审查数据能力——签名请求/上下文/模拟结果/标签的统一 schema，合成场景生成器，币安事件回归用例，数据卡与可复现划分。
- `tx-risk-engine`: 审查引擎能力——解码、确定性模拟、能力/暴露特征、规则/不变量、风险分级决策、JSON 审查报告与 `lab risk` CLI。
- `tx-risk-model`: 审查模型能力——SFT/DPO 数据构造、Qwen3 LoRA 训练、结构化输出约束、推理集成、规则+模型组合与导出/量化复用。
- `tx-risk-eval`: 审查评测能力——标注基准、分场景指标、规则 vs 模型消融、币安回归、可复现报告。

### Modified Capabilities

无。当前 `openspec/specs/` 为空；本变更新增独立的应用实验能力，不改变既有 8 阶段课程的 spec 级行为（`lab stages` 仍为 8 个阶段，新增的 `lab risk` 为独立子命令族）。

## Impact

- 新增代码：`src/bigmodel_lab/risk/`（schema、解码、模拟、特征、规则、决策、流水线、数据集、模型、评测、CLI 子命令、fixtures）；`configs/risk.yaml`、`configs/risk-rules.yaml`；`docs/risk-review.md`；`tests/test_risk_*.py`。
- 修改代码：`src/bigmodel_lab/cli.py` 注册 `risk` 子命令；`README.md` 与 `docs/README.md` 增加应用实验导航。`risk/config.py` 独立校验 `risk:` 配置，不修改 `config.py`、8 阶段注册表与阶段实现。
- 新增依赖：可选 dependency-group `risk`，含 `eth-abi`/`eth-utils`（纯 Python，清华镜像可装）用于 calldata 与 EIP-712 解码；训练复用现有 `train` 组依赖。若解码依赖不可用，引擎支持结构化 JSON 输入降级，保证离线可跑；不引入需要 CUDA 或 GitHub 源码构建的新依赖。
- 资源：场景 fixture 与合成数据入库（小体积，JSON/JSONL）；模型训练复用已下载的 Qwen3-0.6B（约 1.6 GB），不新增大型下载；sanity 档单次运行 ≤10 分钟。
- 数据与安全：不包含真实用户数据、私钥或真实攻击资金；地址与交易为合成或基于公开事件复盘的结构化模拟；不接入 RPC、不广播交易。
- 对现有 8 阶段无破坏性影响；实验产物写入 `runs/risk/<run-id>/` 并沿用现有 manifest 规范。
