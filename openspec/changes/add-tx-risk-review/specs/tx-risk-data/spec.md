# Spec Delta

## Purpose

为交易签名风险审查提供可复现、可扩展的数据集：统一定义签名请求、上下文、模拟结果与标签，覆盖正常运营与高风险场景，并内置币安事件回归用例，支撑规则引擎与审查模型的训练和评测。

## ADDED Requirements

### Requirement: 统一审查样本 schema
系统 SHALL 定义并校验版本化的审查样本 schema，覆盖签名请求（链、账户、操作类型、原始数据或结构化字段）、上下文（来源、时间、审批凭证、账户角色）、模拟结果（资产/授权/权限/代码差分）与标签（动作类型、能力变化、风险等级、资产暴露比例、期望决策、场景族）。

#### Scenario: 合法样本通过校验
- **WHEN** 用户提交带版本号且字段完整的审查样本
- **THEN** 系统完成 schema 校验并返回规范化样本

#### Scenario: 非法或未知版本样本
- **WHEN** 样本缺少必要字段、类型错误或 schema 版本未知
- **THEN** 系统拒绝该样本并给出字段级错误与支持的版本列表

### Requirement: 合成场景生成器
系统 SHALL 提供确定性场景生成器，至少覆盖普通转账、批量提现、approve/permit、EIP-7702 委托、权限变更、代理升级、批量 nonce、跨链组合八类场景；相同种子 MUST 生成相同样本。

#### Scenario: 同种子复现
- **WHEN** 用户以相同种子和场景配置运行生成器
- **THEN** 两次生成的样本内容完全一致，且生成清单记录种子与配置

#### Scenario: 场景覆盖检查
- **WHEN** 用户运行场景覆盖检查
- **THEN** 报告每类场景的正/负样本数量，任一类别缺失时以非零退出码结束

### Requirement: 币安事件回归用例
系统 SHALL 内置基于公开复盘的结构化回归用例，包含 EIP-7702 委托、连续 nonce 批量、全部资产暴露、无审批凭证、服务账号来源与新部署目标合约等关键特征，并标注期望决策。

#### Scenario: 回归用例校验
- **WHEN** 用户校验内置回归用例
- **THEN** 系统确认必填特征与期望决策齐全，特征缺失时报告具体缺口

### Requirement: 数据卡与可复现划分
系统 SHALL 输出数据卡，说明来源与许可、场景构成、标签分布、已知偏差与限制；SHALL 支持按种子与比例生成训练/验证/测试划分，并保证测试集与训练集不共享同一场景实例。

#### Scenario: 划分可复现
- **WHEN** 用户使用相同种子与比例重新生成划分
- **THEN** 划分清单与样本归属完全一致

#### Scenario: 泄漏检查
- **WHEN** 用户对划分结果运行泄漏检查
- **THEN** 系统报告跨集合重复实例，存在泄漏时以非零退出码结束

### Requirement: 数据 CLI 与产物
系统 SHALL 提供 `lab risk data` 子命令，支持生成、校验与查看数据集，产物写入规范化实验目录并附带 manifest、统计报告与数据卡；离线时 MUST 不依赖网络。

#### Scenario: 生成数据集
- **WHEN** 用户执行 `lab risk data generate --out runs/risk/<run-id>`
- **THEN** 目录包含样本文件、统计报告、数据卡与 manifest，且命令退出码为 0

#### Scenario: 校验失败
- **WHEN** 数据集中存在与 schema 不符的样本
- **THEN** 命令报告失败样本位置与原因并以非零退出码结束
